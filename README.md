TaskFlow — Demonstração Gitflow

Sobre o projeto

O TaskFlow é um projeto fictício criado para demonstrar a utilização do Git e do Gitflow em um fluxo de desenvolvimento de software.
Estrutura de branches

O projeto utiliza três branches principais:

prod: versão de produção.

develop: ambiente de desenvolvimento e integração.

feature/add-task: desenvolvimento de novas funcionalidades.

Objetivo da demonstração

Demonstrar a organização do código, o controle de versões, a colaboração por meio de Pull Requests e a importância da revisão de código em um ambiente de desenvolvimento profissional.
